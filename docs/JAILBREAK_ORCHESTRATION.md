# Оркестрация публичных jailbreak-компонентов

> Исторический документ. С 2026-11-06 направление отменено в пользу
> [кастомизации старых iOS](LEGACY_CUSTOMIZATION.md). Модуль не подключён к продукту.
> Приведённая ниже матрица не является подтверждённой аппаратной поддержкой;
> вычисление дайджеста загрузки не является проверкой её подлинности.

Направление проекта 0.2.0. MegaNugget **не содержит и не разрабатывает эксплойтов**.
Он оркеструет публичные upstream-проекты: показывает, какой компонент публично
сообщён для конкретной связки «устройство/версия iOS», загружает официальную
сборку с GitHub, сверяет SHA-256 и размер и документирует шаги на устройстве.
Весь рискованный код исполняется только внутри официального upstream-приложения
на вашем устройстве.

## Поддерживаемая цель и публичные доказательства

Матрица в `crates/jb-orchestrator/src/matrix.rs` документирована из открытых
источников (сверено 2026-11; пометка каждого ряда - в комментариях и ниже):

| Устройства | iOS | Публичный route | Источник |
|---|---|---|---|
| iPhone 7 / 7 Plus (iPhone9,x, A10, arm64) | 15.8.8 | Dopamine **2.5b4** (prerelease), эксплойт DarkSword, канал TrollStore | opa334/Dopamine releases; публичные гайды (2026-08) |
| A9/A10 (6s/6s+/SE1/7/7+, iPhone8,x–9,x) | 15.8.7 | Dopamine 2.5b2+ DarkSword | публичные гайды (2026-04) |
| A9/A10/A11 arm64 | ≤ 15.8.6, 15.0–16.6.1 | Dopamine 2.x stable, эксплойт landa | upstream README/выпуски |
| A11 (iPhone10,x) | ≥ 15.8.7 | **нет проверенного публичного route — матрица отказывается** | отсутствуют доказательства |
| Прочие устройства | — | `no_plan` — нет заявлений | — |

Специфично для iPhone 7 / 15.8.8 важны три явных предупреждения:

1. **Заявленная стабильность — ReportedConcerns**: по публичным отчётам
   iPhone 7/15.8.8 после джейлбрейка бывают загрузочные циклы (bootloops) и
   случайные отключения даже без твиков; единственный публично описанный
   fix — восстановление в DFU. Обязательно сделайте полный бэкап.
2. 2.5b4 — prerelease: DarkSword не поддерживает A8(X), может не работать на
   A9X/раннем iOS 16.x, и иногда завершает приложение аварийно (заметки
   релиза 2.5b4).
3. Route требует TrollStore на устройстве, который ставится по инструкции
   upstream (TrollRestore заменяет системное приложение); это отдельный
   необратимый шаг с заменой системного приложения — выполняйте его вручную
   и осознанно.

## Что уже гарантирует код

- `jb-orchestrator::matrix` возвращает план только для combos, где есть
  публичные доказательства; для «A11/DarkSword» и неизвестных устройств
  ошибка `unverified_route` / `no_plan`, а не выдуманная совместимость.
- `jb-orchestrator::releases` скачивает только содержимое GitHub API
  releases (теги exact-match) с ограничением размера, таймаутами; выдаёт
  `(bytes, sha256)`, не сохраняя артефакты в репозитории. `.tipa` не
  используется — берётся `Dopamine.ipa`; `SystemFetcher` выполняет
  системный `curl` с явными лимитами и кодами ошибок.

## Что остаётся за пределами кода (честно)

- Реальная загрузка релиза по сети **не выполнялась** в этом окружении.
- Оркестратор пока не подключён к Desktop IPC/UI: следующий шаг — команды
  `jb_status` / `jb_prepare` с нативным подтверждением и явными
  предупреждениями из матрицы (страховочный текст о bootloops).
- Установка/TrollStore/Dopamine на устройстве — только вручную пользователем
  следуя документации upstream; MegaNugget не автоматизирует замену
  системного приложения.
- После джейлбрейка могут пострадать хранимые на устройстве данные,
  гарантия и некоторые сервисы (например обновления по воздуху); восстановление
  описано публично как DFU restore. Действия у вас, бэкап обязателен.

## Лицензии и наличие стороннего кода

MegaNugget не поставляет, не пере-лицензирует и не изменяет бинарные или
исходные коды Dopamine/TrollStore. Ссылки и лицензии:

- Dopamine: https://github.com/opa334/Dopamine — GPL-3.0;
- TrollStore: https://github.com/opa334/TrollStore — см. upstream LICENSE;
- TrollRestore: https://github.com/JJTech0130/TrollRestore — см. upstream LICENSE.

Проверенные загрузки остаются артефактами upstream, сохраняются вне git
(каталог загрузок пользователя), с записью SHA-256 в журнале.

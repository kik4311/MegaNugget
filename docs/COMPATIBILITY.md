# Совместимость 0.1.0

| Конфигурация | Классификация | Jailbreak |
|---|---|---|
| iPhone9,1 / iPhone9,3, заявленный iPhone 7 A10 ARM64, iOS 15.8.8 | research_target | not_implemented |
| Другие версии iOS 15 на iPhone 7 | unverified | not_implemented |
| iOS 16/17 на устройствах, которым Apple разрешает эти ОС | unverified | not_implemented |
| Симулятор iOS | unverified | not_implemented |

`research_target` означает совпадение с **целевой конфигурацией пользователя**, а не
подтверждённую физическую проверку наличия этой прошивки, совместимость bootstrap
или работоспособность jailbreak. Реальное устройство/номер сборки пока не проверены.
Не предполагается, что iPhone 7 способен штатно работать на iOS 16 или 17.

Desktop сравнивает ProductType и точную ProductVersion. Архитектура отображается
из устройства при доступности; A10/ARM64 ожидаются по модели, не проверяются отдельным
аппаратным тестом. iOS дополнительно исключает симулятор и проверяет `arm64`.
Для неизвестных/неполных данных совместимость не подтверждается.

Минимальная iOS 15.0 в Xcode означает только deployment target приложения.
Это не матрица jailbreak. Установка зависит от валидной подписи, provisioning,
совместимости бинарника, версии iOS, доступности USB-сервисов и доверия компьютеру.

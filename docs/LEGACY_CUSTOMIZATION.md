# MegaNugget Legacy: направление от 2026-11-06

> Обновление: реальный частичный импорт кода GoldenNugget и офлайн-компилятор
> описаны в [GOLDENNUGGET_PORT.md](GOLDENNUGGET_PORT.md). Системное применение
> по-прежнему не реализовано. Диапазон редактора — iOS 15–17; первая аппаратная
> цель остаётся iPhone 7 / 15.8.8. Ниже сохранён первоначальный аудит.

Цель: возможности кастомизации по образцу GoldenNugget Mobile на старых iOS,
**не jailbreak**. Первый аппаратный target — iPhone 7, `iPhone9,1`/`iPhone9,3`,
arm64, iOS 15.8.8. Другие модели/версии не объявляются поддерживаемыми автоматически.
Deployment target приложения остаётся 15.0; возможность запуска и поддержка твиков — разные вещи.

## Аудит upstream

Источник: https://github.com/GoldenNugget-Team/GoldenNugget-mobile
Ревизия: `e4be86f050f4980ccc58de3b74f9de58b070b705`.

- `project.yml`: deployment target 26.0, зависимость от Minimuxer и EMProxy,
  AirliftFFI, WebKit, SQLite. Нельзя переносить, просто изменив MinimumOSVersion.
- `Nugget/Core/GoldenNuggetEngine.swift`: compile → protective backup → инъекция
  в manifest → restore через mobilebackup2. Это отдельный канал системных изменений,
  не обычная запись из sandbox SwiftUI-приложения.
- `Nugget/Core/TweakCatalog.swift`: версионные ограничения и системные пути.
  Каждый параметр нуждается в отдельном обосновании совместимости с iOS 15.
- `Nugget/Core/StatusBarModel.swift`: конкретный бинарный ABI, не универсальный
  формат для любой iOS. До проверки старой структуры писать такой файл нельзя.
- `Nugget/Core/PosterBoard.swift`: работа с descriptor store и SQLite в домене
  PosterBoard. Нельзя считать этот механизм применимым к iOS 15.
- Корневой `LICENSE` — **AGPL-3.0**. `FORKING.md` называет GPLv3: несоответствие
  зафиксировано, не трактуется как разрешение перелицензирования. Если начнётся
  копирование кода, сохраняются оригинальные notices, лицензии, credits и сведения
  об изменениях. Брендинг и ресурсы upstream не копируются.

## Текущее состояние

| Возможность | Состояние |
|---|---|
| Тема самого MegaNugget | Реализована; локальный AppStorage, без сети/системных изменений |
| Информация об устройстве | UIDevice + uname; без вымышленных данных |
| Каталог status bar / SpringBoard / обоев / служб | Описание направлений, не действующие твики |
| Системное применение на iOS 15.8.8 | Не реализовано, кнопки применения нет |
| Pairing / Minimuxer / backup/restore внутри iOS-приложения | Не перенесены |
| Подпись и установка через Desktop | Существующий механизм сохранён; пользователь сообщил об успехе до смены направления |
| Jailbreak / Dopamine | Не часть текущего продукта |

`CustomizationCatalog` разрешает только локальную тему. Для системных функций
точное совпадение target возвращает `backendNotPorted`, остальные устройства —
`outsideInitialTarget`. Ни одна ветка не разрешает запись в системные файлы.
Исторический `jb-orchestrator` не удалён и не вызывается новым интерфейсом.
Его матрица и прежние заявления о «verified downloads» не являются доказательством:
вычисление SHA-256 само по себе не проверяет подлинность файла.

## Следующий этап

Для первого системного твика сначала подтвердить на iOS 15.8.8:
авторизованный канал чтения/записи, целевой формат, получение исходного значения,
резервную копию, явное согласие, проверку результата и восстановление.
После этого переносить **одну** функцию, а не весь upstream engine сразу.
Наличие pairing record или установленного подписанного IPA не доказывает,
что системная запись доступна. Пароли и pairing records не отправляются в чат/git.

## Проверка

Добавлены Swift unit tests для точного target, локальной темы и запрета системных
операций. На Linux Swift/Xcode отсутствуют, поэтому выполнение этих тестов и сборка
нового SwiftUI требуют macOS CI. Старые зелёные CI не проверяют этот новый интерфейс.
Работа новой сборки на физическом iPhone пока не подтверждена.

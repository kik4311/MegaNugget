# Участие в разработке

1. Прочитайте docs/ARCHITECTURE.md и SECURITY.md.
2. До PR выполните проверки из docs/DEVELOPMENT.md; укажите непроверенные платформы.
3. Не представляйте fixtures, mocks и simulator как проверку на iPhone.
4. Не расширяйте совместимость по диапазону iOS без аппаратного отчёта.
5. Новые мутации требуют системного подтверждения и документированного восстановления.
6. Не коммитьте IPA, профили, сертификаты, идентификаторы или чужой нелицензированный код.
7. Любая исследовательская цепочка требует отдельного review; пока её нет,
   JailbreakEngine обязан сохранять not_implemented.

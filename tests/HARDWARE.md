# Ручная аппаратная матрица

Все пункты ниже **ещё не выполнены**, пока нет отдельного отчёта с доказательствами.

Для нового signer дополнительно: отмена native consent (ноль запросов), неверный пароль,
неверный/истёкший 2FA, несколько Team, нет свободных сертификатов (ни одного отзыва),
недоступный anisette/keyring, несовместимая iOS (отказ до сети), отмена/таймаут после
создания аккаунтных ресурсов (не обещать rollback), успешная подпись и отдельная установка.

| Сценарий | Ожидаемый результат |
|---|---|
| Нет iPhone, usbmuxd доступен | devices=[], ошибки нет |
| Нет CLI | tool_missing; установка disabled |
| usbmuxd недоступен | command_failed, не «устройств нет» |
| iPhone подключён/locked/untrusted | неизвестный доступ либо данные; не утверждать причину отказа |
| iPhone9,1 / 9,3 + точная 15.8.8 | research_target, jailbreak=false |
| Другой build/version/model | не расширять поддержку без доказательств |
| Два iPhone | явный выбор; проверка и установка на выбранный UDID |
| Отмена file picker | IPA сброшен, установки нет |
| Отмена системного подтверждения | ни одной команды установки |
| Подписанный собственный IPA | команды install/browse, совпадение bundle/build |
| Плохая подпись / expired / wrong UDID | ошибка iOS; никаких обходов |
| Кабель отключён при установке | ошибка/таймаут; состояние неизвестно, не «откат» |
| Та же версия уже установлена | наличие доказано, замена содержимого не доказана |
| Экспорт при включённом показе UDID | в JSON нет идентификаторов и путей |
| iOS availability check | not_implemented, никаких системных изменений |

Проверить на каждой desktop ОС и обеих версиях CLI. Не коммитить IPA, provisioning,
сертификаты, сырые device plist. Тестовые ZIP-fixtures генерируются Rust-тестами в temp.

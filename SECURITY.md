# Security policy

MegaNugget 0.1.0 — исследовательский preview, не средство защиты и не jailbreak.
Тестируйте только собственные устройства или с явным разрешением владельца.

Не публикуйте в issue UDID, pairing records, Apple ID, сертификаты, private keys,
mobileprovision, сторонние IPA и необработанные device logs. Используйте обезличенный
экспорт Desktop; он содержит только коды событий и время.

Секреты и telemetry проект не собирает. `PATH`, CLI и выбираемые IPA должны быть
доверенными. Приложение не имеет защиты от локального пользователя с теми же правами
или скомпрометированного libimobiledevice. Автоматической загрузки CLI нет.

Перед публикацией проекта настройте GitHub Private Vulnerability Reporting для
уязвимостей MegaNugget. Сейчас адрес приватного security-контакта не назначен:
не выдумывайте рабочий канал и не отправляйте секреты в публичные обсуждения.
Уязвимости Apple сообщайте через официальный Apple Security Research:
https://security.apple.com/

ПАРА ВАЖНЫХ ОТВЕТОВ

Без мелкого шрифта.

Проект развивается открыто.
Ограничения — тоже.

Это jailbreak?+

Нет. Текущее направление MegaNugget — кастомизация старых iOS без jailbreak. Dopamine не используется приложением. Системный механизм применения настроек пока не перенесён.

Уже можно менять системные обои и status bar?+

Нет. Сейчас работает оформление самого MegaNugget. Строка состояния, SpringBoard, обои и системные службы отмечены в каталоге как недоступные, пока не проверен перенос на iOS 15.8.8.

Это GoldenNugget Mobile?+

Это отдельный проект, ориентирующийся на GoldenNugget Mobile. MegaNugget не является его официальным клиентом или готовым backport. Код и ресурсы upstream пока не копировались.

Можно скачать готовый установщик?+

Готовые Desktop-дистрибутивы пока не настроены: Desktop собирается из исходников. В успешных iOS-заданиях GitHub Actions доступен неподписанный IPA; скачивание артефактов может требовать входа в GitHub. Сам по себе он не устанавливается без подписи.

Сайт собирает мои данные?+

На сайте нет аналитики, форм входа, cookies, внешних шрифтов или запросов к Apple. Все ресурсы страницы локальные. Переходя по ссылке GitHub, вы открываете отдельный сервис с его правилами.
